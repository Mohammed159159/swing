# Project Documentation (`docs/`)

This directory houses the academic, technical, and operational documentation for the Furuta Rotary Inverted Pendulum project.

---

## 📁 Subdirectory Breakdown

```text
docs/
├── logs/               # Weekly meeting minutes, milestone logs, and video links
├── pdfs/               # Reference literature papers and official course descriptions
├── report/             # Final comprehensive technical report source (LaTeX/Word) & figures
│   └── sections/       # Modular report chapters
├── resources.md        # Audited catalogue of 158 technical resources
├── main_doc_instructions.md
├── Furuta Pendulum Project Basic Resources Review.md
└── Furuta Pendulum Advanced Resource Review.md
```

---

## 🎯 Documentation Governance

- **Single Source of Truth:** `HANDBOOK.md` in root defines the operational roadmap, WBS, team accountability, and grading criteria.
- **Contribution Matrix:** `docs/report/contributions.md` records individual task completions and cross-reviews for every team member.
- **Primary Owners:** Pair 4 (Benchmarking & Documentation) with all members contributing to their respective chapters.
